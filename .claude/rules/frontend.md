# Modable UI Quality Standard

Modable is a premium desktop-native developer/consumer AI tool.

The interface must not resemble a generic SaaS dashboard or AI-generated template.

Design references:
- Raycast
- Linear
- Arc
- native macOS utilities

Priorities:
1. hierarchy
2. typography
3. restrained color
4. desktop-native density
5. purposeful motion
6. clear agent state
7. excellent empty/loading/error states

Never consider a meaningful UI task complete from source code alone.

For frontend work:
1. Launch Modable.
2. Navigate to the affected state.
3. Capture screenshots.
4. Critique the rendered result.
5. Fix visual problems.
6. Repeat.
